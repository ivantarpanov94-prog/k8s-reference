🌿 Version Control & Collaboration Guide (Git)

Summary of core concepts, workflows, and essential command references for Git version control (Lectures 1–19).

Core Concepts & Lectures Summary

  • Fundamentals & Setup: Overview of Git, installation, configuration, initializing repositories (git init), staging (git add), and committing (git commit).
  • Branching & Merging: Managing branches (git branch, git checkout / git switch), merging code safely, and handling merge conflicts (git merge --abort).
  • Collaboration & Remotes: Remote repositories, cloning (git clone), fetching (git fetch), pushing (git push), and utilizing pull requests.
  • Advanced Utilities: Temporary work stashing (git stash), release tagging (git tag), and pattern exclusion via .gitignore.

🛠️ Essential Git Command Cheatsheet

# Initialize a new local Git repository
git init

# Stage changes for the next commit
git add [file-name]  # (or use 'git add .' to stage all changes)

# Commit staged changes with a descriptive log message
git commit -m "feat: descriptive commit message"

# Check the current state of working directory and staged files
git status

# List, create, or delete branches
git branch  # (list) / git branch [branch-name] (create)

# Switch to an existing branch
git checkout [branch-name]  # (or git switch [branch-name])

# Merge changes from a target branch into your active branch
git merge [branch-name]

# Abort an active merge process if unresolved conflicts occur
git merge --abort

# View line-by-line diffs of unstaged or uncommitted changes
git diff

# View the repository commit history log
git log --oneline --graph

# Clone a remote repository down to your local machine
git clone [repository-url]

# Download objects and refs from a remote repository
git fetch

# Upload local branch commits to a remote repository
git push origin [branch-name]

# Temporarily stash uncommitted changes to work on something else
git stash  # (restore later with 'git stash pop')

# Create a lightweight or annotated tag for a specific release commit
git tag v1.0.0
